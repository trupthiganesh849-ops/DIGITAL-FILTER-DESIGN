# DESCRIPTION
The design and implementation of a Finite Impulse Response (FIR) filter represent a fundamental milestone in Digital Signal Processing (DSP) and hardware description language (HDL) modeling. This project focuses on developing a 3-tap Moving Average FIR filter using Verilog, specifically optimized for the EDA Playground environment. The core objective is to transform a mathematical difference equation into a physical hardware architecture that can process digital signals in real-time. By utilizing a Direct Form structure, the design ensures that each input sample is processed through a pipeline of delay registers, coefficients, and adders. This specific filter is categorized as a low-pass filter, designed to attenuate high-frequency noise while allowing lower-frequency components of a signal to pass through relatively unchanged.
At the architectural level, the filter is composed of three primary hardware stages: the tapped delay line, the coefficient scaling, and the summation tree. The tapped delay line is implemented using D-flip-flops that function as a shift register, holding previous input samples $x[n-1]$ and $x[n-2]$. In this implementation, we utilize coefficients of $0.25, 0.5,$ and $0.25$. To maximize hardware efficiency, this design avoids the use of expensive dedicated multipliers. Instead, it leverages arithmetic bit-shifting—shifting a binary value right by one bit to divide by two, or two bits to divide by four. This approach significantly reduces the total gate count and power consumption of the circuit, which is a critical consideration in FPGA and ASIC design. By using fixed-point arithmetic, the filter maintains high-speed throughput, capable of producing one filtered output sample for every clock cycle.
The verification of this design is conducted through a robust testbench on EDA Playground, utilizing the Icarus Verilog simulator and EPWave visualization tool. The simulation applies several test vectors, including an impulse response test and a step response test. The impulse response test, where a single high-value sample is followed by zeros, allows the designer to observe the filter's coefficients directly in the output waveform, confirming the mathematical accuracy of the RTL logic. Furthermore, the step response and noise simulation demonstrate the filter’s "smoothing" capability. When the input signal toggles rapidly between extreme values, the filter calculates a weighted average, effectively dampening the oscillations and producing a more stable, averaged output.
In terms of performance analysis, the FIR architecture provides the distinct advantage of inherent stability. Unlike Infinite Impulse Response (IIR) filters, which use feedback and can potentially oscillate, the FIR filter's output is solely dependent on a finite number of past inputs. This makes the design highly reliable for mission-critical applications such as medical instrumentation, audio processing, and sensor data refinement. The 8-bit resolution chosen for this project provides a balanced trade-off between quantization error and hardware complexity. Overall, this project successfully demonstrates the transition from a DSP algorithm to a functional Verilog module, providing a scalable template for more advanced, higher-order filtering systems in modern digital electronics.
